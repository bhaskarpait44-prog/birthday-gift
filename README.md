# 🎂 Happy Birthday Interactive Surprise Web App

A lightweight, beautiful, interactive, and mobile-responsive Happy Birthday surprise website built with HTML5, Tailwind CSS, Canvas Confetti, and CSS Animations.

## ✨ Features

- **🎁 3D Unboxing Gift Box**: Interactive gift box that shakes until tapped and pops open with confetti.
- **🕯️ Realistic Flame Candle Cake**: 3D layer birthday cake with multi-layer fire flame physics, glowing aura halo, and core flame spot.
- **📸 Polaroid Photo Memory & Lightbox**: Styled Polaroid photo card featuring `bh.jpg` with a tap-to-expand high-res Lightbox modal.
- **⚡ Lightweight & Mobile Responsive**: Optimized touch controls, zero heavy icon dependencies, and fast performance on all devices (mobile, tablet, desktop).

## 🚀 Deployment

### Deploying to Vercel
1. Push this repository to GitHub: `https://github.com/bhaskarpait44-prog/birthday-gift`
2. Go to [Vercel](https://vercel.com) and click **Add New Project**.
3. Import your GitHub repository `birthday-gift`.
4. Vercel will automatically detect `index.html` and deploy it instantly!
